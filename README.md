# Desafio de Laboratório II — Labirinto

Projeto acadêmico desenvolvido em Java para praticar recursão, pesquisa, ordenação e estruturas de dados.

## Etapas

1. **Labirinto:** leitura de um arquivo de texto e busca recursiva pela saída, marcando o caminho encontrado.
2. **Pesquisa e ordenação:** geração de candidatos, ordenação estável com Insertion Sort e pesquisa binária por nome.
3. **Estruturas estáticas:** lista e pilha com arrays, contagem recursiva de elementos e verificação de parênteses.
4. **Estruturas dinâmicas:** pilha e fila implementadas com nós encadeados.

## Como executar

Com um JDK instalado, abra o projeto no VS Code e execute a classe principal da etapa desejada:

- `Etapa1.PrincipalLabirinto`
- `Etapa2.PrincipalCandidatos`
- `Etapa3.PrincipalEtapa3`
- `Etapa4.PrincipalEtapa4`

Execute pela raiz do projeto para permitir a leitura dos arquivos de dados. Cada etapa também possui um validador fornecido pela faculdade.
